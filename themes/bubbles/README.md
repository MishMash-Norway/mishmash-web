# UI theme: bubbles

The look mishmash.no had from its launch until September 2026, kept as a
switchable theme: the purple-to-green gradient header with the site name in
Inter, the two overlapping bubbles as the logo and front-page illustration,
and the original purple/green/dark palette in the bubble thumbnails, social
icons and cube figures.

Files here are the pre-identity versions of the corresponding files in
`site/`: the layout (with the front-page bubbles injected from the layout so
the page content stays shared), `custom.css`, `chat.css`, `adaptive.css`, the
bubble, icon and cube images, and the interactive bubbles gallery page.

Run it with:

```bash
./scripts/ui serve bubbles
```

Full guide: [themes/README.md](../README.md).
